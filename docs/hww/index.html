03The Sunday machine

The Sunday desk does not move. Nocturne is the paper. The Night Final is the one Sunday edition. It is not the changelog. Times are Montevideo. A thin week is fine. A padded one is not.

  1. Mon–Sat 08:38Stoop, then Wire. Plus the standing look at Justice Year. No pull request on a weekday from this desk.
  2. Sun before noonThe last sweep. The window closes at 12:00.
  3. Sun 20:03Night Editor, then SEO by DM, then Copy, then pictures, then the stamp, then the pre-flight, then eggbot builds and opens the pull request around 20:00.
  4. Until 23:00The owner merges. Nothing else goes to main while it is open. Weekday pull requests land before 17:00, or they wait.
  5. After mergeA 200 and the headline, then the owner posts the one draft, before 23:00. The draft is not in the pull request.
  6. Not by 23:00The issue does not run.

Handoff never ships. Four paths only. A quiet week with notebook lines gets one pull request, the notebook alone. Eggbot does not build until the SEO file exists. The token lasts one hour. A Night Final is not a release.

04The research loop

The researchers’ loop and the auditors’ loop are the same loop.

  1. DeliverAn outside team delivers its files. Studies, not commits.
  2. DigCursor reopens every cited page and tries to disprove each claim that would change the repo. It does not edit the catalogue in that same turn.
  3. SortHeld, improved, unconfirmed, or wrong. Unopened is unconfirmed.
  4. RuleThe owner rules. Only then does a release pull request open.

The harness runs on the pull request, before the merge, and again on main. 182 guard sections, 1,821 negative fixtures, 555 smoke checks. Chromium and WebKit, with axe. While iterating, the pass can be scoped. The merge gate is the full wall on that commit. A paper-only pull request runs every guard and the paper half of the browser check, on Chromium and WebKit, and skips smoke, the wall and the app half of the browser check. Every push to main runs all of it.

Cursor’s QA reports read the whole repo, each finding with a way to reproduce it. Independent auditors read the live release and do not open work. The owner’s eye covers devices, VoiceOver, High Contrast, and the Sunday review.

A QA-driven cut takes every finding in one release, and anything left out gets its reason. Standing decisions do not reopen because a scanner proposes their opposite.

08The rules

  1. The owner merges. No bot, no session, no auditor lands anything.
  2. Every fact has a source that was opened. Unopened is unconfirmed.
  3. Plans and mocks before code. Measured, not eyeballed.
  4. One source of truth per thing. The Cursor file points at the rules. It is not a second brief.
  5. No new third-party services. Use what is already paid for.
  6. Short, direct, transparent. Say what was not checked.
  7. Weekday pushes go out as the Cursor agent. Not as the owner. Not as the Sunday bot.
