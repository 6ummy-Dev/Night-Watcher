Privacy

Night Watcher is an unofficial fan guide, kept by 6ummy. It is free software. The source is public. This page says what stays on your device, and the one count the paper makes.

The map

The map is the watch orders. There is no account and no sign-in, and no advertising. Nothing tracks what you watch.

What you tick — a title watched, skipped, or rated — stays in this browser. So do the settings: the path, the theme, the filters. None of it is sent anywhere. There is no copy of it on a server.

A backup code is a string you copy yourself. A file you save stays where you put it. The browser only remembers the handle to that file, on this device.

The app can be installed, and it can open offline. The copy it keeps for that is on this device too.

Clearing this browser’s data clears the marks and the settings. It does not delete a file you saved.

The paper

Nocturne is the weekly paper. It is not the map, and it does not read what you have watched.

It does count visits. The count is Cloudflare Web Analytics: no cookies, and nothing that follows you from site to site. The colophon on every issue says the same thing. The map does not carry that counter.

The paper remembers whether you chose Dark deco or Darker, in this browser. If you have not chosen on the paper, it uses the theme you already set on the map. That choice stays on the device.

The paper is not saved for offline. If the network is down, the issue does not open.

Links you follow

Where to watch, Support, and the source on GitHub are links you open. They go to those sites. This site does not bring their counters back with you.
