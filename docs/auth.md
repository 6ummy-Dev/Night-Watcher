# Night Watcher — auth.md

Night Watcher has no authentication, by design.

There is nothing to register, no login, no API keys, no accounts of any kind. Every page and every file this site serves is public and identical for everyone. Watch progress, ratings and skips are stored only in the visitor's own browser and never leave it.

If you are an agent looking for a sign-in flow: there isn't one, and that is the feature.
