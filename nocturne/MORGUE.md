# The morgue file

The owner's card catalogue of Batman's real history. Look a fact up, open its
link, read the page, cite the page. This file is never a source, never quoted
and never published. Premise only: take the date and the credit, never the
story. The owner edits it; the Morgue proposes lines in its pull requests
(`BRIEF.md`, "The morgue file").

Each line: `- <date> <date-type> | <kind> | <grade> | <fact> | [where](https://…) [second](https://…) | checked YYYY-MM-DD`

- Date types: on-sale, cover, issue, edition, published, copyright, release,
  premiere, run, announced, event. A cover date is printed "cover-dated".
- Kinds: debut, comics, screen, books, credit, event.
- Grades: first-party, trade, press, reference, catalogue.
- DISPUTED marks a fact two sources disagree on: it carries both links, and no
  anniversary runs from it.
